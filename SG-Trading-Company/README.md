# SG Trading Company – Official Website

A modern, responsive website for **SG Trading Company**, premier electrical trade merchants and authorized distributors delivering certified electrical components, designer modular switchgear, industrial cables, and energy-efficient lighting solutions.

## 🚀 GitHub Pages Deployment
This website is built with pure, static HTML5, CSS3, and modern JavaScript with zero build dependencies.

To deploy on GitHub Pages:
1. In your GitHub repository, navigate to **Settings** > **Pages** (in the left sidebar).
2. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` and folder `/ (root)`.
3. Click **Save**.
4. GitHub Pages will build and deploy the site in ~1 minute at `https://<your-username>.github.io/<repository-name>/`.
